## Core Task

Given a natural language question about a database, perform the following two analytical tasks:

1. **Schema Linking** — Map entities and concepts in the question to specific tables and columns in the schema.
2. **Value Linking** — Extract concrete data values or filter conditions mentioned in the question.

> ⚠️ **CRITICAL CONSTRAINT**: Output must be **purely analytical**. Do **NOT** generate any executable SQL code under any circumstances.
