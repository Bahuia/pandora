## Common Error Patterns and How to Fix Them

### NameError: name 'xxx' is not defined
→ The variable/table name is wrong. Check the schema.

### KeyError: 'column_name'
→ The column doesn't exist in this table. Check the schema for the correct column name.

### TypeError: '>' not supported between 'str' and 'float'
→ Table values are all strings. Use `pd.to_numeric(df['col'], errors='coerce')` before numeric comparison.
→ **Also check**: Are you using `>` or `<`? You should use `>=` or `<=` instead.

### IndexError: index 0 is out of bounds for axis 0 with size 0
→ Your filter returned no results. Check if you're filtering on the correct column with the correct value.

### AttributeError: 'Series' object has no attribute 'itertuples'
→ You called `.itertuples()` on a Series. Use double brackets: `df[['col']]` to keep it as a DataFrame.

### TypeError: 'int' object is not iterable
→ You wrapped a scalar value in `list()`.
→ **Scalar-returning methods (e.g., `.nunique()`, `.count()`, `.sum()`, `.max()`, `.min()`) return a SINGLE NUMBER, NOT a list.**
→ **Fix:** Remove `list()`. If the result format requires a list of tuples, wrap it manually.
- ❌ **WRONG:** `result = list(df['col'].nunique())` → `list(5)` raises TypeError!
- ❌ **WRONG:** `result = list(df['col'].count())`
- ✅ **CORRECT:** `result = [(df['col'].nunique(),)]` → Returns `[(5,)]`
- ✅ **CORRECT:** `result = [[df['col'].nunique()]]` → Returns `[[5]]`
