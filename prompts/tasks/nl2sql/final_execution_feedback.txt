### [T] TypeError: Type mismatch in comparison

```
TypeError: '<' not supported between instances of 'float' and 'str'
TypeError: '<=' not supported between instances of 'str' and 'float'
```

**Checklist:**
- [ ] **[T-1]** Does the error involve a date column (`dob`, `birthday`, `date`, `First Date`)? These columns often contain empty strings `''`. **Fix**: `pd.to_datetime(col, errors='coerce')` → filter with `.notna()`.
- [ ] **[T-2]** Are you calling `.min()` / `.max()` / `.idxmin()` / `.idxmax()` on a column that may contain empty strings? **Must convert first**.
- [ ] **[T-3]** Did you merge after converting a date column? Merge can introduce new empty values. **Re-convert after merge**.
- [ ] **[T-4]** Does the column contain a mix of valid dates and `None`/`''`? Filter: `df[(df['col'].notna()) & (df['col'] != '')]`

### [A] AttributeError: Wrong method on object type

```

```

**Checklist:**
- [ ] **[A-1]** Did you call `.min()` / `.max()` / `.sum()` / `.mean()` and then `.itertuples()`? These return **Series**, which has no `.itertuples()`.
- [ ] **[A-2]** Are you calling `.itertuples()` on a scalar value? **Scalars can't use itertuples**.

**Correct patterns:**
```python
# ❌ WRONG: .min() returns Series, no itertuples

# ✅ CORRECT: use nsmallest to keep DataFrame
result = list(df.nsmallest(1, 'CreaionDate')[['CreaionDate']].itertuples(index=False, name=None))
```
